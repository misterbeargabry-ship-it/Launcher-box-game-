# GAMEBOX PC — sito ufficiale (starter)

Sito statico responsive, pronto per essere pubblicato con GitHub Pages, Netlify o Vercel.

## Pubblicazione rapida con GitHub Pages
1. Carica `index.html` nella cartella principale di un repository GitHub.
2. Apri **Settings → Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Seleziona il branch `main` e la cartella `/ (root)`, poi salva.
5. Attendi la pubblicazione e apri l'indirizzo mostrato da GitHub Pages.

## Personalizzazione
- Il pulsante di download apre la pagina Actions del repository configurato.
- L'artifact di GitHub Actions non è un link permanente: può scadere secondo le impostazioni di retention di GitHub.
- Per una distribuzione stabile, pubblica una Release GitHub e aggiorna il link nel pulsante.
- La grafica di anteprima è illustrativa, non uno screenshot reale dell'app.

## Accuratezza
Il testo descrive GAMEBOX PC come launcher Windows. Non dichiara che sia un emulatore console. L'esecuzione degli APK richiede un emulatore Android esterno e ADB.
